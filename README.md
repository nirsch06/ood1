Software Overview:
----------------
Name: College Management System
Description: A management system for academic institutions supporting lecturers, 
departments, and committees. The system handles serialization for data persistence.

Features:
----------------
- Management of lecturers (including doctors and professors).
- Department and committee organization with membership validation.
- Data persistence using Java Serialization.
- Advanced comparison tools for articles and departmental statistics.

Instructions:
----------------
1. Running the project:
   - Compile all Java files: javac *.java
   - Run: java Main
2. Testing:
   - Use the interactive menu to add entities and run comparisons.
   - Data is automatically saved to 'college_data.bin' upon exit.
