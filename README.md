Software Overview:

Name: Gradle Unit Testing Assignment
Description: This project demonstrates the implementation and execution of unit tests using Gradle and JUnit. It includes logic for validating the functionality of core classes and systems within the Object-Oriented Design framework.

Features:
----------------
- Gradle-based build management.
- Comprehensive unit testing suite using JUnit for automated validation.

Instructions:
----------------
1. Running the project/tests:
   - Ensure Java JDK and Gradle are installed.
   - Run the following command in the terminal from the root folder:
     ./gradlew test
2. Testing Instructions:
   - Test reports are generated in: build/reports/tests/test/index.html.
   - Open this file in a browser to view the test results summary.
